# 10 Cards Layout Using HTML and CSS

## 📌 Practical Details
**Subject:** Full Stack Development 1

**Practical:** Create ten cards using HTML and CSS, featuring an image at the top, along with a card title and description. Align these cards horizontally on the page.

## 🎯 Objective
To design and develop ten attractive cards using HTML and CSS. Each card contains an image, a title, and a short description.

## 🛠️ Technologies Used
- HTML5
- CSS3

## ✨ Features
- Ten individual cards.
- Image at the top of each card.
- Title and description for every card.
- Horizontal card layout using CSS Flexbox.
- Hover animation effect.
- Responsive layout for different screen sizes.
- Attractive design with rounded corners and shadows.

## 📂 Project Structure

10-Cards-Layout/
│
├── index.html
├── style.css
└── README.md

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Double-click on `index.html`.
4. The project will open in your web browser.

## 📸 Output
The webpage displays ten cards with images, titles, and descriptions arranged horizontally using CSS Flexbox.
