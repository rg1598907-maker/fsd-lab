# Practical 01: Three Concentric Circles

## Subject
Full Stack Development 1

## Aim
To draw three concentric circles having radii of 10px, 20px, and 30px using different colors.

## Technologies Used
- HTML5
- CSS3

## Project Structure
Practical_01_Concentric_Circles/
│
├── index.html
├── style.css
└── README.md

## Description
This practical demonstrates how to create three concentric circles using HTML and CSS.

All three circles have the same center but different radii and colors.

## Circle Details

| Circle | Radius | Diameter | Color |
|--------|--------|----------|-------|
| Inner  | 10px   | 20px     | Yellow |
| Middle | 20px   | 40px     | Blue |
| Outer  | 30px   | 60px     | Red |

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in any web browser.

## Output
Three concentric circles with different colors.
